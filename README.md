# Nook releases

Download builds of [Nook](https://browser.arunbrahma.com), a quiet web browser for the Mac.

Latest DMG: https://github.com/iamarunbrahma/nook-releases/releases/latest/download/Nook.dmg

Each release is signed with a Developer ID certificate and notarized by Apple. A SHA-256 checksum ships next to the DMG. Nook runs on Apple silicon and Intel Macs.

Nook's source code is not published here.
